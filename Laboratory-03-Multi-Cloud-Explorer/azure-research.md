# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform provided by Microsoft. It offers many cloud services for computing, storage, databases, networking, security, artificial intelligence, and application development. Organizations can use Azure to build, run, and manage applications and other IT resources in the cloud.

## Global Infrastructure

Azure has a global infrastructure made up of regions and datacenters located in different parts of the world. Microsoft currently lists more than 70 Azure regions and more than 400 datacenters. This global infrastructure helps organizations choose locations that can support their performance, data residency, and availability requirements.

Azure also uses Availability Zones in supported regions. Availability Zones are separate physical locations within an Azure region that can help organizations design applications with greater resilience.

## Cloud Management Console

The Azure portal is a web-based, unified console used to create and manage Azure resources. Users can use the portal through a web browser to build, manage, and monitor resources such as virtual machines, databases, web applications, and storage.

The Azure portal also provides tools such as search, dashboards, resource management, monitoring, and cost information. This makes it easier for users to manage their Azure subscription through a graphical interface.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provides virtual machines that allow users to run applications and operating systems in the cloud. Users can select different virtual machine sizes and configurations depending on their workload requirements.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data. It can be used to store files, documents, images, videos, backups, and other types of data.

### 3. Azure SQL Database

Azure SQL Database is a fully managed relational database service based on the Microsoft SQL Server database engine. It allows organizations to run databases in the cloud without managing the underlying database infrastructure themselves.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage users, groups, applications, and access to resources.

## Three Advantages

### 1. Strong Microsoft Integration

Azure works closely with Microsoft technologies such as Windows Server, Microsoft 365, Active Directory, and other Microsoft products. This makes Azure useful for organizations that already use Microsoft's technologies.

### 2. Global Infrastructure

Azure has a large global infrastructure with regions and datacenters in many locations around the world. Organizations can select suitable locations for their applications based on factors such as performance, availability, and data residency.

### 3. Wide Range of Services

Azure provides many different cloud services for computing, storage, databases, networking, security, artificial intelligence, and application development. This allows organizations to build and manage many types of cloud solutions on one platform.

## Typical Enterprise Use Cases

Enterprises can use Azure to host websites and applications, run virtual machines, store business data, manage databases, and support enterprise software. Azure can also be used for backup and disaster recovery, data analytics, artificial intelligence, and hybrid cloud environments.

Organizations that already use Microsoft technologies can use Azure to extend their existing IT infrastructure into the cloud.
