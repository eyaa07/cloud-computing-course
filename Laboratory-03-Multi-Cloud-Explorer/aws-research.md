# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many cloud services that organizations can use for computing, storage, databases, networking, security, and application development. AWS allows businesses to use cloud resources without having to manage all of the physical hardware themselves.

## Global Infrastructure

AWS has a global infrastructure made up of geographic Regions and Availability Zones. An AWS Region is a physical geographic area where AWS has cloud infrastructure. Each Region contains multiple Availability Zones, which are separate locations designed to help applications remain available and reliable.

AWS Regions are located in different parts of the world, including North America, South America, Europe, Asia Pacific, the Middle East, and Africa. Organizations can choose a Region based on factors such as the location of their users, performance, legal requirements, and data residency needs.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can search for services, create and manage cloud resources, view account information, monitor resources, and access different AWS service consoles.

The console makes it easier for users to manage AWS resources through a graphical interface instead of using only command-line tools.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides virtual servers in the AWS Cloud. Organizations can use EC2 instances to run websites, applications, and other workloads.

### 2. Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service. It allows users and organizations to store and retrieve files and other types of data using storage containers called buckets.

### 3. Amazon RDS

Amazon Relational Database Service (Amazon RDS) is a managed relational database service. It helps organizations set up, operate, and scale relational databases while AWS handles many common database administration tasks such as backups, patching, and provisioning.

### 4. Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows users to create a logically isolated virtual network in AWS. Organizations can use a VPC to control IP addresses, routing, network connections, and access to AWS resources.

## Three Advantages

### 1. Wide Range of Services

AWS provides many different services for computing, storage, databases, networking, security, analytics, and other cloud needs. This allows organizations to build different types of applications using one cloud platform.

### 2. Global Infrastructure

AWS has Regions and Availability Zones in different parts of the world. This allows organizations to place their resources closer to their users and design applications that can be more highly available.

### 3. Scalability

AWS allows organizations to increase or decrease cloud resources based on their needs. This can help businesses handle changes in application demand without having to purchase and maintain large amounts of physical hardware.

## Typical Enterprise Use Cases

Organizations can use AWS for many different business purposes. Common examples include hosting websites and applications, storing and backing up data, running databases, developing software, and supporting large-scale business systems.

AWS can also be used by enterprises that need highly available applications, global infrastructure, data storage, and scalable computing resources.
